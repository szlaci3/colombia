# Formlane release roadmap

The finish line is a portfolio-ready release. Each milestone includes automated checks, a checked commit and push, and verification on [Netlify](https://formlane.netlify.app).

1. [x] **Improve content import:** local pasted Markdown, search/type filters, full previews, and capacity-aware selection. Website imports and original Markdown exports remain available.
2. [x] **Expand templates:** blog, social feed, and dashboard with the shared brand and existing editor blocks. Article, post, and metric layouts stay editable and portable; earlier v1 projects gain the new starter pages.
3. [x] **Strengthen meeting workflows:** a device-local named project library, durable named versions with undoable restoration, and current/all-template print-to-PDF handouts. Existing saves migrate; shared snapshots get separate project slots.
4. [ ] **Add the AI assistant:** implemented the server-side provider adapter, context choice, before/proposed review, validated atomic operations, undo, cancellation, and a clearly labeled local example. **2026-10-21 repair:** reproduced the enabled production timeout and replaced Gemini 3.8/Generate Content with Gemini 3.5 Flash-Lite/Interactions, a live-compatible wire schema, and platform-safe deadlines. Real brand, selected-hero, and table-header proposals pass local provider checks, including local browser generation/review/apply/undo. **Remaining:** verify the deployed configuration and opt-in hosted review/apply/undo check after the automatic deployment.
5. [ ] **Create the introduction:** short explainer video and a polished guided example.
6. [ ] **Polish and harden:** mobile usability, accessibility, performance, and failure handling across the complete release.
7. [ ] **Finish the portfolio release:** case study, final architecture documentation, full tests, and verified deployment.

The current foundation includes six templates; shared themes and source style review; website and local Markdown content import; inline and structural editing; history; presentation; named projects and saved versions; PDF handouts; local autosave; project files; shareable snapshots; and the reviewed assistant workflow. Hosted verification of the assistant repair remains open in milestone 4. The introduction video and guided example follow in milestone 5.
